# Release Queue

Release Queue measures a personal media queue against the time remaining until a selected game releases. GTA VI is the initial target. Users can search for another game and its release date in Settings, or enter a title and date manually.

## Language

**Release Queue** is the product name, independent of the target game.

**Target game** is the game whose release date sets the countdown and forecast.

**Queue** is the ordered collection of games, shows, movies, books, podcasts, and YouTube playlists the user plans to finish.

## Save compatibility

Keep the historical browser storage keys and portable save markers. Preserve old GTA Queue and Time Bridge imports. Switching targets keeps the queue, progress, completed history and schedule.
