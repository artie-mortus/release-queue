# Icons

The icon artwork is embedded in `index.html`, so it needs no external request, package or build step.

The selected set is Material Symbols Rounded with filled shapes, except for books and podcasts, which use Heroicons solid. These match option B with the two option C substitutions selected in the icon comparison.

Material Symbols are distributed under the Apache License 2.0 in `Material-Symbols-LICENSE.txt`. Heroicons are distributed under the MIT License in `Heroicons-LICENSE.txt`.

`sources.json` maps each stable sprite identifier to its upstream SVG. The sprite retains each source's viewBox, and CSS supplies color and display size. The identifiers remain stable across the queue, search results, navigation and planning views.
